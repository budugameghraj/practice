## 🎤 During the Interview

### Step 1: Understand (5 min)
```
✅ Listen carefully
✅ Ask clarifying questions
✅ Confirm input/output format
✅ Discuss edge cases
✅ Ask about constraints
```

**Example Questions:**
- "Can the array be empty?"
- "Are all numbers positive?"
- "Can I modify the input?"
- "What's the expected time complexity?"

### Step 2: Examples (3 min)
```
✅ Walk through given examples
✅ Create your own test case
✅ Think of edge cases
✅ Verify understanding
```

### Step 3: Approach (7 min)
```
✅ Think out loud
✅ Discuss brute force first
✅ Identify pattern
✅ Propose optimal solution
✅ Discuss time/space complexity
```

**Template:**
```
"Let me start with a brute force approach...
We could iterate through... [explain]
This would be O(n²) time.

But I notice this is a [pattern name] problem.
We can optimize using [technique]...
This would bring it down to O(n) time."
```

### Step 4: Code (20 min)
```
✅ Start coding only after approval
✅ Write clean, readable code
✅ Use meaningful variable names
✅ Add comments for complex logic
✅ Think about edge cases while coding
```

### Step 5: Test (5 min)
```
✅ Walk through your code with example
✅ Test edge cases
✅ Check for off-by-one errors
✅ Verify time/space complexity
```

## 💬 Communication Tips

### Do's ✅
1. **Think out loud**: Share your thought process
2. **Ask questions**: Clarify ambiguities
3. **Explain trade-offs**: Why you chose this approach
4. **Stay calm**: Take a breath if stuck
5. **Write clean code**: Readable > clever

### Don'ts ❌
1. **Jump to code**: Understand first
2. **Stay silent**: Interviewer wants to hear your thinking
3. **Give up easily**: Show problem-solving ability
4. **Argue**: Be open to hints
5. **Memorize**: Understand the pattern

## 🚫 When You Get Stuck

### Strategy:
1. **Take a breath**: Don't panic
2. **Re-read problem**: Maybe you missed something
3. **Try examples**: Work through manually
4. **Think patterns**: What pattern fits?
5. **Brute force**: Start with obvious solution
6. **Ask for hint**: It's okay to ask!

### What to Say:
```
"Let me think through this step by step..."
"I'm considering a few approaches..."
"Can I think out loud for a moment?"
"Could you provide a hint about [specific aspect]?"
```
