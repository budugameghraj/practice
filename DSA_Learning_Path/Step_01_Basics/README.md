# Step 1: Learn the Basics

## 🎯 Overview

This is the foundation of your DSA journey. Master these basics before moving forward!

**Estimated Time**: 2-3 weeks (for beginners), 1 week (for those with Python experience)

## 📚 Topics Covered

### 1.1 Python Basics & Syntax
Learn Python fundamentals needed for DSA:
- Data Types (int, float, str, bool)
- Input/Output operations
- Operators & Expressions
- Conditionals (if-elif-else)
- Loops (for, while)
- Functions
- Lists, Tuples, Sets, Dictionaries
- List Comprehensions
- Lambda Functions
- Built-in Functions (sorted, map, filter, reduce)

### 1.2 Pattern Problems
Build logical thinking through pattern printing:
- Square patterns
- Triangle patterns
- Number patterns
- Character patterns
- Hollow patterns
- Diamond patterns
- Floyd's triangle

### 1.3 Basic Math Operations
Essential mathematical concepts:
- Count Digits
- Reverse a Number
- Check Palindrome
- GCD/HCF
- LCM
- Armstrong Numbers
- Prime Numbers
- Prime Factorization
- Divisors

### 1.4 Recursion Fundamentals
Understanding recursion from ground up:
- What is recursion?
- Base case & recursive case
- Print N to 1 using recursion
- Print 1 to N using recursion
- Sum of first N numbers
- Factorial
- Fibonacci
- Reverse an array
- Check if string is palindrome
- Multiple recursion calls

### 1.5 Basic Hashing
Introduction to hashing:
- What is hashing?
- Hash Maps/Dictionaries in Python
- Frequency counting
- Character hashing
- Number hashing
- Finding duplicates

## 🎓 Learning Path

1. **Day 1-3**: Python Basics & Syntax
   - Complete all basic Python problems
   - Get comfortable with input/output
   
2. **Day 4-7**: Pattern Problems
   - Start simple, build complexity
   - Focus on loop logic
   
3. **Day 8-10**: Basic Math
   - Mathematical thinking
   - Optimize solutions
   
4. **Day 11-15**: Recursion
   - MOST IMPORTANT! Take your time
   - Draw recursion trees
   - Understand stack calls
   
5. **Day 16-18**: Hashing
   - Learn dictionary operations
   - Time complexity analysis

## 💡 Key Concepts to Master

1. **Time Complexity**: Understand O(1), O(n), O(n²), O(log n)
2. **Space Complexity**: Understand auxiliary space
3. **Edge Cases**: Always consider empty inputs, single elements, large numbers
4. **Python Specifics**: 
   - Integer division: `//` vs `/`
   - Power: `**` or `pow()`
   - Range: `range(start, end, step)`
   - List slicing: `arr[start:end:step]`
